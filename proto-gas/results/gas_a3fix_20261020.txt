The slow path as its own rows (same after-wasm, so no load shift in these differences):

| slow path | cost Ggas | host ops added | when |
|---|---:|---|---|
| at_mut first write, record already has the marker | +22 vs a 2nd write | +1 record read | once per collection (header absent) |
| at_mut first write, record without the marker | +130 vs a 2nd write | +1 record read, +1 record write | once per collection |
| Lazy::set below a record, value absent | +137 beyond load | +1 has_key (Lazy key), +1 record read | each absent -> present set |
| Lazy::set below a record, value present | +63 beyond load | +1 has_key (Lazy key) | every set: Lazy has no header to answer in memory |

(The first write with the marker present costs more than a 2nd write only by the record read: the
same row before the rule was 53 Ggas cheaper than the 2nd write because its trie walk was shorter.)

DAO (near-sdk/tests/state_v2_dao.rs vote_op_counts): the first vote into a proposal's empty
`votes` map reads the proposal record once (7/8/0 instead of 6/8/0, >2000 bytes read); the
one-time read scales with the parent record's size. Later votes are unchanged.
