# Slim-down pass A, round 3 (collections.rs): both maps' remove_step hash the finishing path once (Oct 22 2026)
# Fixes: 732050f0 (Map) and 4cd9bc06 (LookupMap).
# - Map::remove_step: `finish_cost` hashed the index path, then `remove_inner` hashed it again.
#   `remove_step_in` now lets `finish_cost` hand what it computed to `finish`, so the index path is
#   hashed once, still only on the call that finishes (Pending and absent calls hash as before).
#   `remove_inner` takes both paths from its caller; `remove` and `discard` hash them in the same
#   order as before.
# - LookupMap::remove_step: finishing called `discard(k)`, which re-hashed the entry path (and
#   re-ran the live check). It now calls `discard_at(&path)`, the body `discard` shares.
# Storage bytes and host ops are unchanged (r/w/d/h identical on every row).
#
# before: 7bcea7ef (the LookupMap remove_step rows added to the ext wasm; collections.rs as at dfb39aee).
# after: 4cd9bc06 (collections.rs identical at HEAD). Both built at the same worktree path.
# remove_step rows: cd proto-gas/sim && GAS_RES_DIR=<wasm dir> cargo +1.95.0 test --test storage_v2_gas remove_step_rows -- --include-ignored --nocapture
# other rows: the same command with `a3_rows` (round-1 rows) and `zst_rows` (round-2 rows).
